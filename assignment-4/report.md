# Клиническая аннотация генетических вариантов — вариант 35

## Исходные данные и методы

Проанализирован файл `student_35.vcf` (GRCh38), содержащий 50 однонуклеотидных вариантов. Поля VCF: CHROM и POS задают хромосому и позицию; ID содержит rsID; REF и ALT — референсный и альтернативный аллели; QUAL, FILTER и INFO в данном файле не заполнены (`.`).

Аннотация выполнена через Ensembl VEP REST API, NCBI ClinVar E-utilities и gnomAD GraphQL API (датасет `gnomad_r4`). Для ClinVar использованы поиск по rsID и VCV-аксессионам, получение ESummary и обязательная проверка точного совпадения GRCh38 SPDI с исходными позицией, REF и ALT. Частоты gnomAD приведены отдельно для экзомов и геномов. Полные настройки сохранены в `annotation_settings.json`.

Для каждого исходного ALT выбран транскрипт с наиболее тяжёлым последствием по шкале Ensembl. При равной тяжести приоритет: MANE Select, MANE Plus Clinical, canonical, protein-coding, затем лексикографически минимальный ID транскрипта. Дополнительные картирования на alternate contigs и последствия других ALT того же rsID исключены. Все транскрипты сохранены отдельно в `vep_transcripts.tsv`.

## Результаты

- Всего 50 SNV: 10 на хромосоме 21 и 40 на хромосоме 22.
- Транзиции: 44; трансверсии: 6; отношение Ti/Tv = 7,33.
- По выбранным транскриптам VEP: 30 missense (включая два с `NMD_transcript_variant` и один с `splice_region_variant`), 18 synonymous, один stop-gained и один вариант полипиримидинового тракта/интрона.
- Записи gnomAD найдены для 49 вариантов; для rs2507733 вариант отсутствует в `gnomad_r4`.
- Точно соответствующие записи ClinVar найдены для 14 вариантов: 11 benign/likely benign, один VUS и две записи с конфликтующей классификацией. Патогенных или вероятно патогенных интерпретаций для исходных аллелей не найдено.

Сводная таблица всех 50 вариантов: `annotated.tsv`. `NA` означает отсутствие значения, а не нулевую частоту; ClinVar «нет» означает отсутствие найденной записи именно для указанного аллеля.

## Разбор трёх вариантов

**1. rs115706909, SDF2L1, 22:21643926:C>T.** По правилу наиболее тяжёлого последствия VEP выбран `ENST00001093571`: `c.220C>T`, `p.Arg74Ter`, stop-gained. Он может приводить к укорочению белка или к нонсенс-опосредованному распаду РНК, но это зависит от транскрипта. Принципиально, что в MANE Select/canonical `ENST00000248958` (`NM_022044.3`) тот же вариант синонимичен: `c.417C>T`, `p.Gly139=`. В gnomAD AF экзомов = 9,3744×10⁻⁵, геномов = 6,9651×10⁻⁴. Записи ClinVar для C>T нет. Поэтому клиническая патогенность не установлена; одного предсказания stop-gained в альтернативном транскрипте недостаточно для патогенной классификации.

**2. rs116712499, SUSD2, 22:24187576:G>A.** В MANE Select `ENST00000358321` (`NM_019601.4`) это missense `c.1897G>A`, `p.Val633Met`. SIFT предсказывает deleterious (0), PolyPhen-2 — possibly damaging (0,717). AF gnomAD: 5,2773×10⁻⁵ в экзомах и 2,4967×10⁻⁴ в геномах. ClinVar `VCV003172261.1`: **Uncertain significance**, один сабмиттер с указанием критериев, последняя оценка 23.01.2024; заболевание не указано. Вариант редкий и функционально интересный, но предсказания in silico не доказывают патогенность; текущая клиническая интерпретация — VUS.

**3. rs115686643, LARGE1, 22:33316147:G>A.** В MANE Select `ENST00000397394` (`NM_133642.5`) это synonymous `c.1389C>T`, `p.Tyr463=`, то есть аминокислота не меняется. AF gnomAD: 3,5572×10⁻⁵ в экзомах и 3,9437×10⁻⁵ в геномах. ClinVar `VCV000902052.11`: **Conflicting classifications of pathogenicity**, последняя оценка 20.02.2025; указаны мышечные дистрофии-дистрогликанопатии A6/B6. Конфликт классификаций необходимо сохранять явно: вариант нельзя считать ни достоверно патогенным, ни достоверно доброкачественным по этим данным. У того же rsID существует другой аллель T с stop-gained, но он не относится к исходному G>A и не использовался в этой интерпретации.

## Заключение

Наиболее интересны rs115706909 из-за транскрипт-зависимого stop-gained, rs116712499 из-за редкости, неблагоприятных предсказаний и статуса VUS, а также rs115686643 и rs116555717 из-за конфликтующих клинических классификаций. При этом ни один исходный вариант не имеет подтверждённой патогенной/вероятно патогенной интерпретации ClinVar.

Ограничения: результат VEP зависит от версии транскриптов и не является экспериментальным доказательством; SIFT/PolyPhen применимы не ко всем последствиям. Отсутствие записи ClinVar не означает доброкачественность, а VUS или конфликт классификаций не позволяют сделать клинический вывод. Частоты gnomAD зависят от популяционного состава, покрытия и типа секвенирования; экзомные и геномные AF нельзя безоговорочно объединять. Наконец, данные актуальны только на дату запроса, а для клинической интерпретации необходимы фенотип, зиготность, наследование, функциональные данные и полная оценка по критериям ACMG/AMP.
