# Клиническая аннотация генетических вариантов — вариант 35

## Файлы репозитория

| Файл | Назначение |
|---|---|
| `Assignment 4.pdf` | Условия задания |
| `student_35.vcf` | Исходный VCF с 50 SNV в координатах GRCh38 |
| `annotated.tsv` | Итоговая таблица: 50 строк, по одной на исходный вариант |
| `report.md` | Краткий отчёт, разбор трёх вариантов и заключение |
| `vep.json` | Исходный результат Ensembl VEP REST API |
| `vep_transcripts.tsv` | Последствия для всех транскриптов каждого исходного аллеля |
| `clinvar.json` | Ответы ClinVar ESearch и ESummary |
| `gnomad.json` | Ответы gnomAD GraphQL API, включая AC, AN и AF |
| `annotation_settings.json` | Параметры запросов и правила обработки результатов |
| `main.py` | Скрипт аннотации и формирования таблиц |

## Структура итоговой таблицы

`annotated.tsv` использует разделитель табуляции и содержит следующие поля:

| Поле | Содержимое |
|---|---|
| `variant` | Координаты и аллели в формате `CHROM:POS:REF>ALT` |
| `source_id` | Идентификатор из исходного VCF |
| `gene` | Ген из выбранной аннотации VEP |
| `vep_consequence` | Наиболее значимое последствие по VEP |
| `transcript` | Выбранный транскрипт |
| `mane_select` | Идентификатор MANE Select или `NA` |
| `canonical` | Признак canonical-транскрипта или `NA` |
| `hgvsc` | Описание изменения на уровне кодирующей последовательности |
| `hgvsp` | Описание изменения на уровне белка |
| `sift` | Предсказание SIFT |
| `polyphen` | Предсказание PolyPhen |
| `rsid` | rsID варианта |
| `gnomad_exome_af` | Частота аллеля в экзомах gnomAD |
| `gnomad_genome_af` | Частота аллеля в геномах gnomAD |
| `clinvar_present` | Наличие записи ClinVar для точного REF/ALT |
| `clinvar_interpretation` | Клиническая интерпретация ClinVar |
| `clinvar_accessions` | Версии VCV-аксессионов ClinVar |

`NA` означает отсутствие значения, а не нулевую частоту. Значение `нет` в поле `clinvar_present` относится к указанному REF/ALT, а не ко всем аллелям с тем же rsID.
